==============================================
 Claude Code 설치 방법 (새 사용자용)
==============================================

[ 준비물 ]
- Windows 10 또는 11 컴퓨터
- 인터넷 연결
- Claude 계정 (claude.ai 에 로그인할 수 있는 계정, 유료 요금제 필요)


[ 설치 순서 ]

1. ClaudeCode_설치.exe 를 더블클릭한다.

   * "Windows의 PC 보호" 파란 창이 뜨면
     → [추가 정보] 클릭 → [실행] 클릭
   * 백신이 막으면 잠시 "허용"으로 바꾼 뒤 다시 실행

2. 검은 창이 뜨면 Enter 를 누른다. 나머지는 자동으로 진행된다.
   - 중간에 "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 가 뜨면 [예]
     (Git 설치 때 뜰 수 있음)
   - 크롬/엣지가 켜져 있으면 "닫을까요?" 라고 물어본다.
     Enter(=예)를 누르면 잠시 닫고 즐겨찾기를 추가한다.
     (다시 열면 "페이지 복원" 버튼으로 탭을 되살릴 수 있음)
   - 전체 5~10분 정도 걸린다.

3. "설치 완료!" 가 뜨면 Enter 를 눌러 창을 닫는다.

4. 바탕화면의 [Claude Code] 아이콘을 더블클릭한다.
   → 브라우저가 열리면 Claude 계정으로 로그인
   → 로그인이 끝나면 검은 창에서 바로 대화를 시작하면 된다.
   (로그인은 보안상 자동으로 할 수 없어 직접 해야 함)


[ 설치 후 바탕화면에 생기는 것 ]

  workspace 폴더   작업 파일이 모이는 곳 (Claude Code 가 여기서 일함)
  Claude Code      더블클릭하면 workspace 에서 Claude Code 실행
  Claude.ai        웹 버전 claude.ai 열기

  크롬/엣지 즐겨찾기 바에도 "Claude" 가 추가된다.


[ 알아두면 편한 명령 ] (PowerShell 창에서)

  q  또는 ㅂ          workspace 폴더로 이동
  q 폴더이름          workspace 안의 폴더로 이동 (Tab 으로 이름 자동완성)
  claude              Claude Code 실행 (작업마다 허락을 물어봄)
  cc 또는 ㅊㅊ        Claude Code 를 허락 묻지 않고 실행 (익숙해진 뒤에 사용)

  Claude Code 안에서
  /c-push             변경 내용을 git 에 커밋하고 올리기
  /help               사용 가능한 명령 보기


[ 문제가 생기면 ]

- 설치 끝에 "확인할 항목"이 나오면 그 화면을 캡처해 두세요.
- 설치 프로그램은 여러 번 실행해도 안전합니다. (이미 된 것은 건너뜀)
- 기존 설정 파일은 덮어쓰기 전에 같은 이름 + .bak 으로 백업됩니다.
