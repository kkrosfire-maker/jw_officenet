==============================================
 Claude Code 설치 방법 (Mac용 / 새 사용자용)
==============================================

[ 준비물 ]
- macOS 12 이상 (Apple Silicon·Intel 모두 가능, 자동으로 알아서 판별)
- 인터넷 연결
- 맥 로그인 암호 (설치 중 한두 번 물어봄. 입력해도 화면에 안 보이는 게 정상)
- Claude 계정 (claude.ai 로그인 가능, 유료 요금제 필요)


[ 설치 순서 ]

1. ClaudeCode_설치_Mac.zip 을 더블클릭해 압축을 푼다.

2. 압축 푼 폴더의 install.command 를 실행한다.
   * 더블클릭했을 때 "확인되지 않은 개발자" 라며 막히면
     → 파일을 [우클릭] → [열기] → 다시 [열기]
   * 그래도 안 되면 터미널(응용 프로그램 > 유틸리티 > 터미널)에 아래를 입력
       bash ~/Downloads/ClaudeCode_설치_Mac/install.command
     (압축 푼 위치에 맞게 경로 수정. 폴더를 터미널 창에 끌어다 놓으면 경로가 입력됨)

3. Enter 를 누르면 나머지는 자동으로 진행된다.
   - "명령줄 개발자 도구 설치" 창이 뜨면 [설치] 클릭 (처음 한 번, 몇 분 걸림)
   - 맥 암호를 물어보면 입력 후 Enter
   - 전체 10~20분 정도 걸린다.

4. "설치 완료!" 가 뜨면 터미널을 닫는다.

5. 바탕화면의 [Claude Code] 아이콘을 더블클릭한다.
   → 브라우저가 열리면 Claude 계정으로 로그인 (직접 해야 함)


[ 설치 후 바탕화면에 생기는 것 ]

  workspace 폴더   작업 파일이 모이는 곳
  Claude Code      더블클릭하면 workspace 에서 Claude Code 실행 (cc 와 같음)
  Claude.ai        웹 버전 claude.ai 열기
  Antigravity IDE (workspace)
                   workspace 폴더가 열린 편집기. 아래쪽 터미널에서
                   q, ㅂ, cc, ㅊㅊ 와 /c-push 등 스킬을 그대로 쓸 수 있음


[ 알아두면 편한 명령 ] (터미널에서)

  q  또는 ㅂ          workspace 폴더로 이동
  q 폴더이름          workspace 안의 폴더로 이동 (Tab 으로 이름 자동완성)
  claude              Claude Code 실행 (작업마다 허락을 물어봄)
  cc 또는 ㅊㅊ        Claude Code 를 허락 묻지 않고 실행

  Claude Code 안에서
  /c-push             변경 내용을 git 에 커밋하고 올리기
  /help               사용 가능한 명령 보기


[ 참고 ]

- 크롬/엣지 즐겨찾기는 맥에서는 자동 추가하지 않는다 (바탕화면 Claude.ai 사용).
- 설치 프로그램은 여러 번 실행해도 안전하다. (이미 된 것은 건너뜀)
- 기존 설정 파일(.zshrc 등)은 덮어쓰기 전에 .bak 으로 백업된다.
