# 동일약품 검색기 (안드로이드) — work_drug_search_android

PC용 요율표 검색기(`../work_drug_search`)의 안드로이드 버전. 네이티브 Kotlin + Jetpack Compose.
요율표 엑셀을 앱에 **내장**(서버·네트워크 없음). 한국어로 소통하고 루트 CLAUDE.md 규칙을 따른다.

## 확정된 디자인·동작 (시안: 바탕화면 `동일약품 검색기 모바일 앱 화면_(261124).png`, 소스 `../work_drug_search/mobile_design/mockup.html`)
- 이름 `동일약품 검색기`, 제목 옆에 `(요율표 26.11)` 회색(제목 절반 크기). 기준 엑셀 선택 칸 없음.
- 검색 버튼 오른쪽 ▼ = 검색 대상 드롭다운(제품명·성분·대조의약품, 정확히 일치). 기본: 앞 3개 체크, 정확히 일치 해제. 최소 1개는 유지.
- 표시할 항목: **항상 접힌 상태로 시작**(`7/8` 개수 표시). 기본값은 대조의약품만 끔(요율 켬). 바꾸면 결과에 바로 반영.
- 정렬: 성분순(기본, 성분→약가↑→요율↓) / 약가순(낮은 순) / 요율순(높은 순) / 사용자 설정(**준비 중**, 비활성). 정렬 규칙은 PC 버전 `default_sort_key` 와 같은 골격(단일제→복합제, 성분명, 함량순, 약가↑, 요율↓, 동률은 제품명)이되 **모바일이 더 정교하다**(`Data.kt` Row.init): ① 함량은 괄호 안 `(20mg as atorvastatin)` 의 값으로 묶는다(염 포함 20.7/21.7 이 같은 20mg 그룹) — 염 무게보다 큰 값은 오타라서 염 무게의 정수부로 보정, ② 괄호 밖 `/` 로만 복합제를 나누고 뒤가 단위(`mg/g`, `mg/ml`, `50μg/ml`)면 농도 표기로 보고 단일제로 취급. PC 버전은 아직 예전 규칙(두 문제가 남아 있음).
- 카드: 제품명(제목) 바로 아래에 성분(**버건디 `Burgundy`**)·대조의약품, 오른쪽에 약가·요율 배지(배지가 높아도 성분은 제목에 붙어 있음 — 제목+성분을 한 Column 으로 묶고 배지는 옆 Column), 그 아래 보험코드·제약사명(**녹색**), 맨 아래 비고. 엑셀에서 빨간 글씨였던 행은 제목이 빨강.
- 제품명 표시: 뒤에 붙은 성분명 괄호 `(아토르바스타틴)` 은 화면·복사·공유에서 뺀다(`Row.displayProduct`). 숫자로 시작하는 괄호 `(2:1)` `(1회용)` 와 용도 표시 `(비만)` `(피임)` `(SR)` 등은 남김. **검색은 원본 제품명 전체를 대상**으로 하므로 `아토르바스타틴`·초성으로 찾는 건 그대로 된다.
- **글자 복사**: 카드 안 글자를 꾹 눌러 끌면 삼성 폰처럼 글자 단위로 선택·복사된다(`SelectionContainer`, 시스템 Copy/Select all 툴바).
- **체크 모드**: 카드 **왼쪽 초록 막대 영역**이나 **약가·요율 배지**를 꾹 누르거나, 결과 머리글의 `선택` 버튼을 누르면 켜진다(글자 꾹 누르기=글자 선택과 안 겹치게 글자 밖 영역을 씀). 카드마다 체크박스가 생기고 탭으로 체크/해제, 머리글에 `N건 선택됨 · 전체선택 · 취소`. 뒤로가기=체크 모드 종료. 새 검색을 하면 자동 해제.
- **내보내기 규칙**: 체크 모드 켬 → 체크한 카드만, 꺼짐 → 검색 결과 전체. 체크 모드인데 체크가 0건이면 "체크한 항목이 없습니다". `이미지 저장`·`클립보드 복사`·`공유하기` 모두 같은 규칙. 이미지는 화면 캡처가 아니라 **`CardImage.kt` 가 카드를 직접 그린다**(헤더 + 카드, 1080px 폭). 40건씩 나눠 여러 장(다운로드 폴더에 `동일약품검색_날짜시각_1.png, _2.png…`). 클립보드는 이미지 1장만 가능해서 40건 넘으면 첫 40건만 복사하고 안내.
- **비고**: 카드에서 처음엔 접혀 있고 `비고 ▼` 를 누르면 그 카드만 펼쳐진다. 펼친 카드는 내보낸 이미지에도 비고가 들어간다.
- **성분 보충 설명**: `(20mg as atorvastatin)` 같은 괄호는 성분명 아래 줄에 회색·10sp(성분 글자의 80%)로 분리(`Row.ingredientMain/ingredientNote`). 괄호를 빼면 글자가 없어지는 이상한 경우는 원문 그대로.
- **빠른 스크롤바**: 목록 오른쪽 끝, 스크롤 중에 나타나 1.4초 뒤 사라지고 끌면 그 위치로 이동(`FastScrollbar`). 아래로 내려가면 오른쪽 아래 `맨 위로` 원형 버튼.
- **드롭다운 닫기**: 검색 대상·정렬 메뉴는 메뉴 밖을 누르면 닫히고, 펼친 `표시할 항목` 패널도 패널 밖을 누르면 접힌다(누른 동작은 그대로 전달).
- **한글 입력**: 검색창은 `String` 이 아니라 `TextFieldValue` 로 들고 있어 한글 조합이 유지된다. **에뮬레이터는 Gboard 에 한국어가 기본으로 없다** → 입력창에서 Gboard 설정(톱니바퀴)→Languages→ADD KEYBOARD→Korean→2-Bulsik→Done, 이후 키보드의 지구본 키(또는 Shift+Space)로 전환. PC 키보드로 한글을 치면 에뮬레이터에는 영문으로만 전달된다.
- 하단 버튼: `공유하기`(결과를 줄글로 공유 시트에 전달, 최대 300건) / `클립보드 복사`(이미지로 복사) / `이미지 저장`(PNG를 다운로드 폴더에 저장). 대상은 아래 "내보내기 규칙" 참고.
- 초성 검색: 검색어에 초성 자음(ㄱ~ㅎ)이 섞이면 글자별 초성 비교(`ㅇㅌㄹㅂㅅㅌㅌ`, `아ㅌㄹ` 가능). 영문인 성분에는 적용 안 됨. 쉼표(,)로 OR 검색.
- 정렬 드롭다운은 `검색 결과 N건` 줄 오른쪽(왼쪽에 `선택` 버튼). 정렬 규칙 문구("성분 → 약가↑ → 요율↓")는 메뉴 안에서만 보임. 설정(톱니바퀴) 버튼은 제거함.

## 구조
- `app/src/main/java/com/jw/drugsearch/`
  - `Data.kt` Row 모델·`rates.json` 로드 / `Search.kt` 검색(초성)·정렬·표시 포맷 / `MainActivity.kt` Compose 화면 / `Actions.kt` 캡처(PixelCopy)·클립보드(FileProvider)·다운로드 저장(MediaStore)·공유
- 데이터: `app/src/main/assets/rates.json` (`tools/export_rates.py` 로 생성)
- minSdk 29(다운로드 폴더 저장에 MediaStore 사용), targetSdk 36, 패키지 `com.jw.drugsearch`

## 요율표 갱신 방법 (매달)
1. `python -X utf8 tools/export_rates.py "<새 요율표.xlsx>"` — 엑셀 읽기는 PC 검색기 `excel_utils.load_rate_sheet` 를 그대로 사용. 파일명 `(26.12)` 에서 버전을 뽑아 제목 옆에 표시.
2. `.\gradlew.bat assembleDebug` 로 APK 재빌드 → 폰에 설치.
- 약가/요율 칸에 `'208'` 같은 숫자 문자열이 있으면 숫자로 변환해서 내보낸다(PC 버전은 이 값을 "값 없음"으로 정렬하지만 모바일은 숫자로 정렬). `-`, `미정` 은 문자열 그대로 보여주고 정렬은 맨 뒤.

## 빌드·검증
- `$env:JAVA_HOME='C:\Program Files\Eclipse Adoptium\jdk-21.0.12.8-hotspot'; .\gradlew.bat assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk` (디버그 서명, 폰에서 "알 수 없는 앱 설치" 허용 필요)

- **검증용 훅**: `adb shell am start -n com.jw.drugsearch/.MainActivity --es q "검색어"` — adb 로는 한글 입력이 안 돼서, 이 값으로 검색어를 넣고 바로 검색한다.
- 스크린샷은 `adb shell screencap -p` 후 `adb pull`(PowerShell 리다이렉트는 PNG가 깨짐). 팝업 메뉴를 탭한 직후 바로 캡처하면 닫힌 화면이 찍히는 경우가 있어, 열린 상태는 `uiautomator dump` 로 함께 확인.
