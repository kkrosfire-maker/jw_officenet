한진택배정산 v1.0 사용 설명

[처음 한 번]
1. 폴더째 원하는 곳에 풀고 한진택배정산.exe를 실행합니다. (설치 필요 없음, Microsoft Edge 필요)
2. PW 칸에 한진 사이트 비밀번호를 입력합니다. [ID/PW 기억하기]가 체크되어 있으면 다음부터 자동으로 채워집니다.
   (PW는 이 PC·이 윈도우 계정에서만 풀리게 암호화되어 config.json에 저장됩니다. 다른 PC로 옮기면 PW만 다시 입력)

[매월 정산]
1. 정산월 확인(기본: 지난달) → [자동 다운로드]
   - 화면에 창을 띄우지 않고 백그라운드에서 로그인 → 운임 정산 현황 → 기간 설정 → 검색 → 전체 체크 → 선택 조회 → 세부내역 엑셀다운까지 진행하고, 끝나면 Edge를 닫습니다(10초 안팎). 진행 상황은 로그 칸에 나옵니다.
   - 다운로드가 끝나면 파일을 자동으로 불러오고, 동일인 후보가 있으면 [동일인 정리] 창이 바로 열립니다(아래 3번).
   - 중간에 멈추면 멈춘 단계를 알려주고 그 화면을 logs 폴더에 캡처해 둡니다.
   - 자동이 안 되면: 사이트에서 직접 받은 파일을 [파일 선택]으로 고르거나 창에 끌어다 놓으세요.
2. 미리보기에서 총 건수·금액·기간과 노란 경고를 확인합니다. 파란 행은 처음 나온 송하인입니다.
3. [동일인 정리]: 같은 사람이면 이름 칩을 끌어서 대표로 쓸 카드에 놓습니다. 아니면 후보 옆 [다른 사람].
   - 잘못 묶었으면 이름을 다른 카드로 다시 끌어 옮기거나, 위쪽 '따로 떼기' 칸에 놓습니다.
   - 칩을 우클릭하면 '대표명으로 지정'으로 대표 이름을 바꿀 수 있습니다.
   - '저장된 판정' 탭에서 지난 판정을 하나씩 취소할 수 있습니다. [저장]을 눌러야 반영되고, 한 번 저장한 판정은 다음 달부터 다시 묻지 않습니다.
4. 표의 호실·전화번호 칸을 더블클릭해 입력하면 송하인마스터.xlsx에 바로 저장됩니다(선택).
5. [정산 엑셀 생성] → 저장 위치 확인 → 완료 후 [파일 열기]/[폴더 열기].
   출력 금액 합계가 원본 합계와 1원이라도 다르면 저장하지 않고 알려줍니다.

[폴더 안 파일]
- 송하인마스터.xlsx : 호실·전화번호·동일인 판정(학습 데이터). 엑셀에서 직접 고쳐도 됩니다(프로그램에서 저장하기 전에 엑셀은 닫아주세요).
- output\    정산 결과 엑셀
- downloads\ 자동 다운로드 원본(삭제하지 않음)
- backup\    송하인마스터 백업(최근 30개)
- logs\      실행 로그, 자동 다운로드 실패 시 화면 캡처

[문제가 생기면]
- 자동 다운로드가 아예 안 될 때: 명령 프롬프트에서  한진택배정산.exe --check-browser  실행 후 logs\browser_check.txt 확인
