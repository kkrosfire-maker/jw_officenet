# CLAUDE.md (marketing_homepage_JW 폴더 전용)

정원유니어스 홈페이지 리뉴얼 작업 폴더. 이 폴더 안에서만 적용되는 규칙.

## 자동 실행 규칙

- HTML을 만들거나 수정하면, 사용자가 따로 말하지 않아도 **완료 후 자동으로 Chrome에 띄운다.**
- 띄우기 전에 `open_site.bat`이 최신 버전 파일을 가리키는지 확인하고, 아니면 먼저 고친다. (`.html` 기본 앱이 없는 PC라 더블클릭 불가 → bat 사용)
- 실행 후 창 제목(`Get-Process chrome`의 MainWindowTitle)으로 떴는지 확인하고 보고한다. 화면 내용을 직접 못 봤으면 그렇게 말한다.
- 띄우기 전에 Playwright 캡처로 먼저 검증한다 (루트 CLAUDE.md의 "참고 자료는 실제로 보고 나서 작업" 규칙 그대로).

## 파일/버전

- 새 버전은 `index_(yymmdd)_...html`로 저장하고 이전 버전은 보존한다. 같은 날 여러 번이면 `261106b`, `261106c`처럼 뒤에 알파벳.
- 섹션 번호는 화면의 좌상단 표 기준으로 부른다 (1 히어로, 2 소개 슬로건, 3 서비스 카드, 4 정산 프로세스, 4-1 티커, 5 선택 이유 카드, 6 제약사 네트워크, 7 FAQ, 8 CSO 소식, 9 문의, 10 푸터).
## 게시판(CSO 업계 소식) 구조

- 데이터: `news/posts.json`(원본) → `news/posts.js`(`window.POSTS`, 화면이 읽음). 둘 다 `admin_server.py`가 같이 갱신하므로 **직접 수정하지 말 것**(수정했다면 `python admin_server.py --build`).
- 화면: `news.html`(목록, 4열·12개/페이지·페이지네이션), `news_view.html?id=`(상세), 홈 8번 섹션은 최신 3개 + `더보기 ›`→`news.html`.
- 홈 파일명은 버전마다 바뀌므로 `news/config.js`의 `HOME_URL`을 새 홈 파일명으로 **매번 같이 갱신**한다 (`open_site.bat`도).
- 관리자: `admin_start.bat` 더블클릭 → `http://127.0.0.1:8787/admin.html` (등록/수정/삭제, 썸네일은 `assets/news/`에 저장). 포트 **8765는 tools_program_board 서버가 사용 중이라 쓰면 안 됨**(8787 사용). Windows에서 `allow_reuse_address`를 켜면 포트가 겹쳐 열리니 끈 채로 둘 것.
- 썸네일: 등록 시 올린 이미지를 그대로 사용(표시는 4:3 크롭). 파일명은 `assets/news/<id>_<시각>.jpg`(교체할 때마다 새 이름 → 캐시 방지, 이전 파일 삭제). `assets/news_thumbnail_0*.jpg`로 시작하는 기존 3개 글은 **임시 이미지**이며, 관리자 목록의 `썸네일 교체` 버튼으로 바꾼다(관리자에서 올린 이미지가 아니면 `임시 이미지` 배지가 뜸).
- 한계: 이 구조는 **내 PC에서만** 글이 저장된다. 실제 웹 호스팅에 올리면 관리자 업로드는 동작하지 않으므로 별도 백엔드/서비스가 필요하다.
- 테스트할 때는 `posts.json`을 건드리지 말고(가짜 글은 Playwright route로 주입), 시험 등록 글은 끝나면 삭제해 원상복구한다.

- 브랜드: 메인색 #003C24, 로고는 `assets/logo.png`(대시보드 아이콘). 정산 4단계 문구는 임시.
