# 대체약 찾기 — 안내서

약 이름을 치면 성분·함량·제형이 같은 **대체 가능한 급여 약**을 가격순으로 보여 주는 웹사이트입니다.

이 폴더는 **독립된 프로그램**입니다. 다른 사이트나 계정과 연결되어 있지 않고, 비밀번호나 키도 필요 없습니다. 자유롭게 고쳐서 쓰시면 됩니다.

---

## 1. 준비물

| 프로그램 | 용도 | 받는 곳 |
|---|---|---|
| Python 3.10 이상 | 화면 띄우기, 자료 만들기 | https://www.python.org/downloads/ (설치 때 "Add python.exe to PATH" 체크) |
| Claude Code (선택) | 말로 시켜서 고치기 | https://claude.com/claude-code |

## 2. 화면 띄워 보기

1. 압축을 풀고, 이 폴더에서 터미널(PowerShell)을 엽니다.
2. 아래 명령을 붙여넣습니다.

```
python -m http.server 8000 --directory public
```

3. 브라우저 주소창에 `http://localhost:8000` 을 넣습니다.
4. 끝낼 때는 터미널에서 `Ctrl + C` 를 누릅니다.

`index.html` 을 더블클릭해서 열면 자료를 못 불러옵니다. 꼭 위 방법으로 띄워 주세요.

## 3. 어디를 고치면 되나요

| 고치고 싶은 것 | 파일 |
|---|---|
| 화면 구성, 문구 | `public/index.html` |
| 색, 글씨 크기, 배치 | `public/style.css` |
| 검색 방식, 결과 표시 | `public/app.js` |
| 개인정보처리방침 | `public/privacy.html` |
| 심평원 자료를 읽어 들이는 방식 | `scripts/build_data.py` |

Claude Code를 쓰면 이 폴더에서 실행한 뒤 "검색 결과에 ○○ 칸을 추가해 줘"처럼 말로 시키면 됩니다. `CLAUDE.md` 에 프로젝트 설명이 있어 자동으로 읽습니다.

## 4. 약 자료 최신으로 바꾸기 (매달 1번)

**약 가격과 목록은 자동으로 바뀌지 않습니다.** 심평원 자료가 매달 1일 기준으로 바뀌니, 매달 초에 직접 돌려 주세요.

처음 한 번만:

```
python -m pip install -r requirements.txt
```

매달:

```
python scripts/build_data.py
```

심평원이 해외 IP를 막기 때문에 **한국 인터넷에서만** 됩니다.

화면 위쪽에 표시되는 기준일로 자료가 언제 것인지 확인할 수 있습니다.

## 5. 주의할 점

1. **가격·대체 가능 여부를 손으로 고치지 않습니다.** 약 정보는 심평원 공공자료 그대로 보여 줘야 합니다.
2. **`주성분코드_동일제형` 이 같은 약만 대체 후보로 묶습니다.** 이 기준을 바꾸면 대체 가능 여부가 틀어질 수 있습니다.
3. **다른 사람에게 공개한다면** 화면의 문의 연락처와 `public/privacy.html` 의 내용을 실제 운영자 정보로 맞춰 주세요.

## 6. 인터넷에 올리고 싶을 때 (선택)

`public` 폴더가 사이트 전체입니다. 본인 Vercel 계정에 이 폴더를 올리면 주소가 새로 생깁니다. `vercel.json` 설정이 이미 들어 있습니다.
