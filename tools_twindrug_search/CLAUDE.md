# 대체약 찾기

약 이름을 치면 성분·함량·제형이 같은 **대체 가능한 급여 약**을 가격순으로 보여 주는 웹.

- 구조: 서버 없는 정적 사이트. `public/` 이 사이트 전체. 검색은 브라우저 안에서 `data.json` 으로. 로그인 없음.
- 이 폴더는 독립된 프로그램이다. 외부 계정·저장소와 연결되어 있지 않고 비밀번호·키도 필요 없다.
- 사람용 설명은 `처음읽어주세요.md`.

## 자료 (심평원 공공자료, 둘 다 무료·키 불필요)
1. 약제급여목록및급여상한금액표 — 게시판 `HIRAA030014050000`, 매달 1일 기준(보통 전달 말에 올라옴)
2. 저가약 대체조제 장려금 지급대상 목록 — 게시판 `HIRAA030015000000` (생동인정·생동대조약 표시)

- 묶음 기준 = 1번 엑셀의 `주성분코드_동일제형` (같으면 대체 가능 후보). 바꾸면 대체 가능 여부가 틀어질 수 있다.
- 3번 칸 "같은 성분·다른 함량/규격" = 주성분코드 앞 4자리 + 뒤 3자리가 같은 다른 묶음
- `public/data.json` 의 `items` 한 줄: [제품코드, 제품명, 업체명, 주성분코드(동일제형), 상한금액, 단위, 규격, flags, 비고] / flags: 1=생동인정, 2=생동대조약, 4=일반의약품
- 심평원 사이트 함정: 글 상세는 `bbsDummy.do` 가 아니라 **`bbsDummyKR.do`** 로 열어야 첨부 버튼이 나온다.
  첨부는 `/bbs/bbsCDownLoad.do?apndNo=..&apndBrdBltNo=..&apndBrdTyNo=..&apndBltNo=..`
- 자료는 자동으로 갱신되지 않는다. 매달 초 `python scripts/build_data.py` 를 직접 돌린다.
- 심평원은 해외 IP 를 막는다. 자료 만들기는 한국 인터넷에서만 된다.

## 실행
`fetch` 로 자료를 읽으므로 파일을 직접 열면 안 된다.
`python -m http.server 8000 --directory public` 후 `http://localhost:8000`

## 화면 규칙 (고칠 때 지킨다)
- 밝은 크림 바탕 `#FFFDE7`, 글자·선은 짙은 초록 `#0F4C3A`. 다크 모드 금지.
- 칸과 버튼은 초록 외곽선 + 둥근 모서리. 묶음 제목 아래 초록 가는 줄.
- 큰 글씨, 넓은 줄 간격, 기울임 금지. 제목을 자르지 않는다.
- 색은 뜻이 있을 때만 쓴다. 좋음=초록, 나쁨=빨강.
- 가장 중요한 버튼 하나만 흐린 초록 `#5E9282` 로 채운다.
- 칸마다 큰 번호, 칸 순서 = 할 일 순서. 버튼은 내용 바로 옆에 옆으로 나란히.

## 지킬 것
- 가격·대체 가능 여부를 손으로 고치거나 지어내지 않는다.
- 다른 사람에게 공개할 때는 화면의 문의 연락처(위쪽 줄 + 맨 아래, `tel:` 링크)와 `public/privacy.html` 을 실제 운영자 정보로 맞춘다.
