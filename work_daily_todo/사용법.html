오늘의 할 일 사용법

프로그램 보드 옆에 띄워 두는 세로형 체크리스트 · 한 일은 엑셀로 분석

1실행하기

  • 할일_실행.bat을 더블클릭하면 창이 열려요. (콘솔창은 뜨지 않아요)
  • 프로그램 보드가 켜져 있으면 그 오른쪽 옆에 자동으로 붙어요. 창 위치·크기는 기억해요.
  • 상단 📌 고정을 누르면 다른 창 위에 항상 보여요. 한 번 더 누르면 해제.
  • 하단 종료로 끝내요. 데이터는 입력할 때마다 자동 저장되니 따로 저장할 필요 없어요.

2할 일 추가

  • 입력칸에 내용을 적고 Enter (또는 ＋). 최대 200자.
  • 입력칸 옆 📅로 완료일(마감일)을 미리 정할 수 있어요. 안 정하면 오늘이 마감이에요.
  • 새로 추가한 일은 목록 맨 위로 스크롤돼요.

3화면 구성

  • 상단: 오늘 날짜와 진행바. 진행바는 (오늘 + 밀린 일) 중 완료한 비율이에요.
  • 어제부터 밀린 일 3일 밀림: 이전 날짜에 적었는데 아직 안 끝낸 일이 맨 위에 빨갛게 모여요. 먼저 처리하세요.
  • 오늘: 오늘 적은 일. 미완료가 위, 완료가 아래로 가요.
  • 지난 날 완료한 일은 화면에서 사라지지만 기록은 남아 있어 엑셀에 들어가요.

4각 항목에서 할 수 있는 것

항목에 마우스를 올리면 오른쪽에 버튼이 나타나요.

조작설명
왼쪽 체크 원완료 체크. 완료한 시각이 기록돼요. 다시 누르면 완료 취소.
글자 더블클릭내용 수정. Enter 저장, Esc 취소.
📅완료일(마감일) 지정·변경. 날짜를 비우면 등록일로 돌아가요.
↳후속 작업 추가. 내용을 쓰고 Enter하면 오늘 할 일로 추가되고, 원본 바로 아래에 ↳ 후속으로 붙어요.
✎메모(결과·참고사항) 입력. 접으면 한 줄 미리보기(📝)로 보여요.
✕삭제(확인창이 떠요). 후속 작업은 독립 항목으로 남아요.
D-2 뱃지마감까지 남은 날. D-0은 오늘, D+1은 마감 지남. 누르면 날짜 변경. 완료한 항목은 완료한 날 기준으로 굳어요.

5엑셀로 저장 (분석용)

  • 하단 저장 (엑셀) → 기간 선택(오늘 / 이번 주 / 이번 달 / 전체 또는 직접 날짜) → 저장.
  • 저장 파일은 바로 열려요. 시트 3개:
    • 요약 — 기간 전체 통계(완료율, 후속이 생긴 건 등)
    • 할일기록 — 등록일·요일·할 일·상태·마감일·완료일·걸린 일수·마감 대비·밀린 일수·후속·메모
    • 일별요약 — 날짜별 등록 수, 완료 수, 당일 처리율
  • JPG 이미지 — 오늘 목록(완료/대기)을 한 장의 이미지로 저장해요. 공유·보고용.
  • 하단 전체삭제(목록 맨 아래 작은 글씨)는 화면에 보이는 항목을 모두 지워요. 확인창이 먼저 떠요.
엑셀에 담긴 완료 항목은 저장 직후 화면에서 정리돼요. 기록은 지워지지 않고 다음 엑셀 저장에도 다시 들어가요.
엑셀 파일이 이미 열려 있으면 저장되지 않아요. 닫고 다시 저장하세요.

6알아두기

  • 데이터는 data/todos.json에 있어요. 이 파일을 지우면 기록이 모두 사라지니 지우지 마세요. 백업은 파일을 복사해 두면 돼요.
  • 한글 입력 중 Enter(조합 확정)로는 추가되지 않아요. 글자가 확정된 뒤 한 번 더 Enter.
  • 하루 일과: 아침에 밀린 일 확인 → 새 일 추가 → 끝낼 때마다 체크 → 필요할 때 엑셀로 저장.
