# 오늘의 할 일

프로그램 보드 옆에 붙여 두는 세로형 체크리스트. 사용자가 무엇을 했고 얼마나 걸렸는지 엑셀로 분석하는 것이 목적이다.

## 용어

- **할 일** — 한 건의 항목. 등록일(`date`), 마감일(`due`), 완료 시각(`done_at`), 메모, 후속 원본(`parent`)을 가진다.
- **구역(section)** — 화면에 보이는 자리. `daily`(매일 반복) → `late`(밀린 일) → `today`(오늘) → `upcoming`(해야 할 일) 순서로 위에서 아래로 놓인다.
- **밀린 일** — 완료하지 못한 채 마감일이 오늘보다 앞선 일반 할 일. 구역은 등록일이 아니라 마감일로 나눈다(마감일을 안 정하면 등록일이 마감일).
- **해야 할 일** — 마감일이 아직 오지 않은(D-1 이상) 미완료 할 일. D-0 이 되면 `오늘` 로 내려온다.
- **매일 반복** — 🔁를 켠 할 일. 항상 맨 위 구역에 있고 밀린 일이 되지 않는다. 어제까지 완료한 건 보관되고 오늘 새로 미완료로 되살아난다. 못 한 날은 기록 없이 오늘로 넘어온다.
- **후속 작업** — 어떤 할 일의 `parent` 를 가진 할 일. 원본을 지우면 `parent` 가 비워진다.
- **마감 대비(D-day)** — 기준일 − 마감일. 미완료는 오늘이 기준, 완료한 건은 완료한 날이 기준으로 굳는다. 양수 = 지연(`D+n`), 0 = 당일(`D-0`), 음수 = 여유(`D-n`).
- **보관(archived)** — 엑셀에 담은 완료 항목이나 되살아나기 전의 매일 반복 항목. 화면에서는 사라지지만 기록은 `todos.json` 에 남아 다음 엑셀에도 들어간다.

## 모듈

| 파일 | 맡은 일 | 바꿔 끼우는 곳(seam) |
| --- | --- | --- |
| `ledger.py` | 할 일 규칙 전부: 구역 분류, 매일 반복 갱신, 완료·보관, D-day. 화면·파일을 모른다 | 시계(`clock`), 저장소(`JsonStore` / `MemoryStore`) |
| `report.py` | 엑셀(요약·할일기록·일별요약)과 오늘 목록 JPG | — |
| `docking.py` | 창 제목으로 두 창을 찾아 보드 옆에 붙이기·따라가기·항상 위·시작 위치 | — |
| `app.py` | 화면(JS)이 부르는 `Api` 와 시작. 위 셋을 잇기만 한다 | — |
| `index.html` | 화면. 편집 상태(수정 중·열린 메모·후속 입력)는 `ui` 객체 하나에 모은다 | — |

화면이 부르는 함수는 항상 바뀐 뒤의 전체 상태(`ledger.view()`)를 돌려준다. 화면은 그것을 통째로 다시 그린다.

## 알아둘 것

- 창 제목 `오늘의 할 일` / `정원유니어스 프로그램 보드` 는 두 프로그램이 서로를 찾는 열쇠다. 바꾸면 보드 옆 붙이기가 끊긴다. (`tools_program_board/server.py` 도 이 제목과 `--dock` 인자를 안다.)
- 엑셀 요약 시트는 틀 고정을 걸지 않는다. 걸었다 풀면 pane 없는 selection 이 남아 엑셀이 "복구하시겠습니까?"를 띄운다. (`tests/test_report.py` 가 지킨다.)
- 테스트: `python -m unittest discover -s tests`
