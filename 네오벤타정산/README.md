# 네오벤타 정산문서

매월 받는 **lawdata**(EDI 처방 원본)를 넣으면 **요율표**와 **제품 마스터**로 자동 변환해서
**최종 정산 엑셀**(`2026년 거래처별 세부내역` 시트의 DB 표)에 새 행을 추가하는 로컬 앱.

값이 다르거나, 바뀌었거나, 제한에 걸리는 행만 사람이 확인하면 된다.

---

## 설치와 실행 (Windows)

Python 3.11 이상이 있으면 **`run.bat` 을 더블클릭**하면 끝이다.
처음 한 번은 가상환경(`.venv`)을 만들고 패키지를 깐 뒤(1~2분) 브라우저가 열린다.
그 다음부터는 바로 뜬다. 창을 닫으면 서버가 꺼진다.

`.streamlit/config.toml` 에 첫 실행 이메일 프롬프트를 끄는 설정
(`server.showEmailPrompt = false`)이 들어 있다. 이게 없으면 더블클릭 실행이
콘솔의 이메일 입력에서 멈춘다.

수동으로 하려면:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

### 전용 앱 창으로 (브라우저 없이)

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.venv\Scripts\python.exe desktop.py
```

브라우저 탭이 아니라 윈도우 창 하나로 뜬다. 창을 닫으면 서버도 같이 꺼진다.

## EXE 만들기

```
build_exe.bat   ← 더블클릭
```

`dist\네오벤타정산\네오벤타정산.exe` 가 만들어진다 (폴더째로 약 220MB).
**이 exe 는 폴더 안에 있어야 돈다.** 옮길 때는 `dist\네오벤타정산` 폴더를 통째로 옮긴다.
바탕화면에는 바로가기를 만들어 쓰면 된다.

- 실행하면 검은 콘솔창 없이 앱 창만 뜬다
- 기준정보(`data/`)는 **exe 옆 폴더**에 생긴다. 쓰던 기준정보를 그대로 옮기려면
  프로젝트의 `data` 폴더를 `dist\네오벤타정산\` 안에 복사한다
- 문제가 생기면 exe 옆의 `app.log` 를 본다

> onedir 로 묶는다. onefile 은 Streamlit static 자산이 많아 실행할 때마다
> 수백 MB 를 임시폴더에 풀어서 매우 느려진다.

## 처음 한 번: 초기 설정

1. **요율표 업데이트** 페이지에서 요율표 엑셀(`제품별 수수료` 시트가 있는 파일)을 등록한다.
   첫 요율표는 바로 현재 버전이 된다.
2. **초기 설정** 페이지에서 lawdata·변환엑셀·요율표를 끌어다 놓고
   `미리보기 만들기` → `기준정보 저장`. (요율표는 이 페이지에서도 바꿀 수 있다)
   - lawdata 전체 시트에서 `제품 ↔ 보험코드` 쌍을 모은다
   - 변환자료 `변경명` → 최종 제품명, 구간인센%, 특별인센%
   - 금액인정 → 제약사별 최소 인정금액
   - **보험코드 채우기**: 변환엑셀에만 있어 보험코드를 모르는 제품은 요율표를 거꾸로
     뒤져 코드를 찾는다. **제품명이 정확히 같을 때만** 자동으로 채우고, 비슷하기만 한 것은
     추천만 해준다(용량이 다른 제품이 섞일 수 있다). 끝까지 못 찾으면 `none` 이다.
   - **초기화 대조 리포트**: 변환엑셀 값과 요율표 값이 다른 항목을 보여준다.
     이후 계산에는 **요율표 값**을 쓴다.

## 매달 하는 일

**정산 실행** 페이지에서:

1. lawdata 엑셀과 최종 정산 엑셀을 **끌어다 놓는다**
   (지난번에 쓴 파일은 기억해서 그대로 다시 쓴다. 바꾸려면 `다른 파일` 을 누른다)
2. 정산월을 고른다. lawdata 에 들어 있는 정산월만 목록에 나오고,
   시트가 하나뿐이면 시트는 자동으로 잡힌다. **정산월과 처방월을 함께 보여준다.**
3. 변환 미리보기에서 검토가 필요한 행을 확인한다
4. **검토** 항목을 모두 처리한다 (아래 표)
5. 소액처 요약을 확인한다
6. `최종 엑셀 생성` 을 누르면 두 가지가 만들어진다.
   - 고른 **최종 엑셀에 이번 달 행이 추가**된다 (고치기 전 `data/backup/` 에 백업)
   - **바탕화면**에 `정원유니어스 판매정산내역 (YYMM) 네오벤타.xlsx` 가 생긴다.
     YYMM 은 정산연월이고, 그 해 정산분이 모두 들어간다.
     (26년 10월에 돌리면 26년 1~10월, 27년 1월에 돌리면 27년 1월만)

### 검토 항목

| 코드 | 언제 | 할 일 |
|---|---|---|
| `PRICE_MISMATCH` | lawdata 단가 ≠ 요율표 약가 | 둘 중 하나를 고르거나 직접 입력 (기본값 없음) |
| `PRODUCT_CODE_CHANGED` | 약제명은 아는데 보험코드가 새 코드 | 같은 제품이면 마스터에 코드 추가 |
| `PRODUCT_RENAMED` | 코드·이름 모두 모르지만 비슷한 제품이 있음 | 연결하거나 신규 등록 |
| `NEW_PRODUCT` | 매칭 실패 | 제품명·구간인센·특별인센 확인 후 마스터에 저장 |
| `NOT_IN_RATE_TABLE` | 요율표에 코드가 없음 | 값을 직접 넣거나 제외 |
| `RATE_TABLE_DUP` | 요율표에 같은 코드가 여러 행 | 쓸 행 선택 |
| `NOTE_RESTRICTION` | 요율표 비고의 제한 조건에 걸림 | 포함하거나 제외 |
| `EXCLUDED_PRODUCT` | 마스터에서 제외로 표시한 제품 | 포함하거나 제외 |
| `VALUE_CHANGED` | 최종 DB 의 마지막 적용값과 다름 | 의도한 변경인지 확인 |
| `NO_THRESHOLD` | 제약사 최소 인정금액을 모름 | 금액 입력 (설정에 저장) |
| `DUPLICATE_MONTH` | 최종 DB 에 같은 정산월 행이 이미 있음 | 중단하거나 기존 행 교체 |

검토에서 고른 내용은 모두 `data/change_log.csv` 에 남는다.

## 계산 규칙

- **F 제약사 / G 구분 / I 단가 / L 수수료%** → 요율표
- **H 제품명 / M 구간인센% / N 특별인센%** → 제품 마스터
- **B 처방월 / C 정산월 / D 사업자번호 / E 병원명 / J 수량** → lawdata
- `K 금액 = 수량 × 단가` (수식)
- `O 최종요율 = N + M + L − 1%` (정산수수료 1% 차감, 수식)
- `P 확정금액 = 금액 × 최종요율` (수식). **소액처면 0**
- `S 정산내역확인` = 소액처면 `소액처`

**소액처 판정**: 같은 정산월 안에서 (병원명 × 제약사) 그룹 금액 합계가 그 제약사의
최소 인정금액보다 작으면 그룹 전체를 소액처로 한다. 검토를 모두 끝낸 뒤 다시 계산한다.
최소 인정금액이 '없음'인 제약사는 판정하지 않는다.

> 구분(G)과 제약사(F)는 요율표를 따른다. 과거 최종파일과 다를 수 있다.
> 예: 안국뉴팜 구분 `1` → `3`, 유니메드 구분 `유` → `유니`. 의도된 변경이다.

### 비고의 EDI월은 처방월이다

요율표 비고의 "○월 EDI"는 **처방월**을 뜻한다(정산월이 아님).

| 비고 | 해석 |
|---|---|
| `26년 3월 EDI까지 정산가능` | 처방월 > 2026-03 이면 검토 |
| `25년 11월 EDI부터 정산가능` / `26년 1월 EDI부터 정산재개` | 처방월 < 시작월이면 검토 |
| `신규금지 (26.07 EDI부터)` | 처방월 ≥ 2026-07 **이고** 그 병원이 이 제품의 신규처면 검토 |

해석하지 못한 비고(회수조치, 집중 프로모션 등)와 `제약사별 프로모션` 시트 내용은
막지 않고 해당 행 옆에 **참고**로만 붙는다.

## 요율표 업데이트

요율표는 매달이 아니라 업데이트가 있을 때만 넣는다.

1. **요율표 업데이트**(또는 **초기 설정**) 페이지에서 새 파일을 끌어다 놓는다
2. 현재 요율표와 **우리 제품 코드만** 비교해서 약가·요율·구분·제약사명·비고 변경을 보여준다
3. 항목별로 `승인` 하거나 `이전 값 유지` 를 고른다 (둘 다 변경 이력에 남는다)
4. 승인이 끝나면 새 요율표가 현재 버전이 된다
5. 승인 대기 중인 요율표가 있으면 모든 페이지 상단에 알림이 뜬다

> 요율표는 **올린 파일 제목 그대로** 표시된다 (예: `정원유니어스(주)요율표(26.08)`).

## 기준정보 관리

- **제품 마스터**: 보험코드, 최종 제품명, 별칭, 이전 코드, 구간인센, 특별인센, 제외 여부, 메모.
  검색·정렬·직접 편집. 인센티브는 **%로** 넣는다 (3 = 3%). 요율표 값은 참고로 함께 보여준다.
  보험코드를 모르는 제품은 **`none`(빨강)** 으로 뜨고, 요율표에서 찾은 추천 코드를 같이 보여준다.
- **제약사별 최소금액**: 제약사별 최소 인정금액과 이름 별칭(요율표 → 최종파일 표기)

> 요율표와 값이 다르면 정산할 때 검토 항목으로 뜬다. 예전 값을 계속 써야 한다면
> **제품 마스터를 직접 고친다**. (요율표 값 덮어쓰기 기능은 없앴다)

저장할 때마다 `data/backup/` 에 이전 파일을 백업하고 변경 이력을 남긴다.

## 개발

```
core/       로직 (UI 없음)
  lawdata.py     헤더 기반 로딩, 정산월 필터
  rate_table.py  요율표 로딩, 버전 관리, 버전 간 비교
  master.py      제품 마스터, 설정, 초기화, 백업
  matcher.py     3단계 제품 매칭
  notes.py       비고 제한 조건 해석
  converter.py   매핑, 검토 항목 생성, 소액처 판정
  writer.py      DB 표 행 추가, 종합 B18, 피벗 새로고침
  final_db.py    최종 엑셀 DB 표 읽기
  apply.py       검토 선택을 마스터·설정에 반영
  changelog.py   변경 이력
pages/      Streamlit 페이지
tests/      pytest
```

### 테스트

```powershell
python -m pytest tests -q
```

요율표 파일이 필요하다. `samples/` 에 넣어두거나 환경변수로 지정한다:

```powershell
$env:NV_RATE_TABLE = "C:\...\정원유니어스 요율표.xlsx"
python -m pytest tests -q
```

요율표가 없으면 요율표가 필요한 테스트는 skip 된다.

`core/` 는 UI 를 모른다. `convert()` 는 순수 함수라서 검토 결과(`decisions`)를 바꿔
다시 부르면 전체가 다시 계산된다.
